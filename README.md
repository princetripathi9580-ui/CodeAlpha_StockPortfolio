# CodeAlpha Stock Portfolio Tracker

A simple Python program that tracks stock investments based on hardcoded stock prices, built as part of the CodeAlpha Python Programming Internship.

## Features
- Displays a list of available stocks with prices
- Lets the user enter stock names and quantities to build a portfolio
- Calculates total investment value
- Option to save the portfolio summary to a text file (portfolio.txt)

## Concepts used
Dictionaries, input/output, basic arithmetic, file handling
